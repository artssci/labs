Interactive Attribute Modifications

In this section, you will learn how to modify the attributes of an SVG shape dynamically using Vue.js. You will start by modifying the fill color of a rectangle, then move on to modifying its width dynamically.

Modify the Fill Color of the Rectangle

  1. In your app.js file, add the data property rectFill with the value "blue". See refence image below
  2. In index.html, add a fill attribute with the value "rectFill" to the rectangle
  3. Add the Vue’s v-bind directive v-bind: before the fill attribute
    4.
  4. The rectangle’s fill color is now controlled by Vue. You should see the rectangle's fill color change to blue. Any updates to rectFill in the Vue app will instantly change the rectangle’s color
  5. See refence image below

Modify the Width of the Rectangle

Now, follow the same process to dynamically modify the width of the rectangle.
  1. Define a Data Property for Width: In app.js, add a new property for the rectangle’s width called rectWidth with a value of 100
  2. Bind the Width Attribute in the SVG: In index.html, update the width attribute of the rectangle by adding the v-bind directive and the value "rectWidth"
    3.
  3. Observe the Change: The rectangle’s width is now controlled by Vue. Try changing the value of rectWidth in your Vue app to see rectangle update instantly. If the rectangle doesn't update, try refreshing the live preview by clicking the refresh button
Now, apply what you’ve learned to modify attributes of other shapes!
  1. Choose one attribute to modify for each shape:
    • Circle: fill (color) or r (radius)
    • Ellipse: fill (color) or rx (horizontal radius)
    • Line: stroke (color) or stroke-width (thickness)
    • Triangle (Polygon): fill (color) or stroke (outline color)
    • Pentagon (Path): fill (color) or stroke-width
  2. Add Vue Data Properties: In app.js, create a data property for the attribute you chose. See example below
  3. Bind the Attribute in the SVG: Update the SVG element in index.html to bind the chosen attribute using v-bind

  4. Observe your changes: Observe how the attribute updates dynamically on the live preview. See reference image below

Hiding or showing SVG elements interactively

In this section, you will learn how to dynamically show or hide SVG elements using Vue.js. Instead of removing elements from the DOM (v-if), we will use the v-show directive, which toggles the visibility of elements by modifying their CSS display property.
  1. In app.js, create a new data property that will determine whether the rectangle is visible
  2. In index.html, use Vue’s v-show directive to control the visibility of the rectangle
    3.
  3. The visibility of the rectangle is now controlled by your app.js file. Try changing it to false to make it disappear
    • If isRectangleVisible is true, the rectangle remains visible
    • If isRectangleVisible is false, the rectangle becomes hidden
Now, apply the same concept to show or hide other SVG elements interactively!
  1. Choose a shape (circle, ellipse, line, triangle, or pentagon)
  2. Create a Vue data property (e.g., isCircleVisible: true)
  3. Use v-show in the SVG to control the shape’s visibility
  4. Manually change true to false in app.js and observe the effect
