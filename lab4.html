Creating Reactive Text Display

In Vue.js, reactivity means that when data changes, the displayed content updates automatically. Instead of manually modifying the text inside your SVG code, you can define text data in Vue and let Vue reactively update the text when the data changes.

In this exercise, you will:

  1. Replace static text with Vue’s text interpolation for Vue to control the displayed text
  2. Define the text in vue.js, making the labels reactive
  3. See how Vue automatically updates the displayed text

Step 1: Replace Static Text with Vue Interpolation

  1. Open the index.html file and locate the label you want to update reactively. For example, the label under the <rect> element
  2. Replace the text Rectangle with two pairs of curly brackets, like {{ }}
  3. Choose a data property name, like rectangleLabel and type it inside the curly brackets. 
    4.

    The data property name should: 1) Start with a lowercase letter - e.g., rectangleLabel, not RectangleLabel. 2) Use only letters and numbers - no spaces or special characters. 3) Use the CamelCase naming convention where the first word is lowercase, and each following word starts with an uppercase letter - e.g., circleLabel, pentagonColor.

  4. Save your changes and check the live preview. The Rectangle label will disappear — this is expected because Vue doesn’t know what rectangleLabel is yet. We will define it in the next step.

Step 2: Define the Label in Vue

Now, let's define rectangleLabel inside vue.js.
  1. Open vue.js and update your data() section:
    • Type rectangleLabel: "Rectangle" below the comment // Add your data properties here
    2.
  2. Save your file. The Rectangle label should reappear because Vue is now controlling it! Try other names such as "My Rectangle" or "Square"

If the live preview does not update immediately, try refreshing the window by clicking the ⟳ icon in the live preview.

Now, make all shape labels reactive by following the same steps:
  1. In index.html, replace the static text inside each <text> element with Vue’s {{ }} syntax
    • ⚠ Choose a meaningful name for each shape’s data property (e.g., circleLabel)
  2. Define a corresponding data property for each shape in vue.js (e.g., circleLabel: "Circle")
    • ⚠ Add a comma after any previous properties under Vue's data()
  3. Test your changes! See if the labels display in the live preview
    • You can also try modifying the labels' text inside vue.js to see how the automatically update in the live preview

Creating Reactive Shape Properties

In Vue.js, just like we can make text reactive, we can also make SVG attributes reactive. This means Vue can automatically update an SVG shape's properties like color, size, or position when the underlying data changes.

In this exercise, you will:

  1. Use Vue's v-bind directive to sync an SVG attribute to a Vue data property
  2. Make the height, radius, stroke, and fill of your shapes react to Vue's data

Step 1: Replace Static Attribute Values with Vue's v-bind Directive

Now, instead of hardcoding static attribute values inside the shapes, we will let Vue control them.
  1. Open index.html and locate the element you want to make reactive. For example, locate the <rect> element
  2. Locate the attribute you want to make reactive, for example the height
  3. Replace the height value with a meaningful data property name such as "rectHeight"
    4.

    Remember: The name should start with a lowercase letter, use only letters and numbers (no spaces or special characters), and use camelCase for multiple words (e.g., circleRadius, rectHeight)

  4. Now, attach a v-bind directive to the height attribute. This will sync (i.e., bind) the attribute to a data property called rectHeight that we will create in the next step
    5.
  5. Save your changes. At this point, you will notice the square disappears in the live preview — this is expected because Vue doesn’t know what rectHeight is yet. We will define it in the next step.

Step 2: Define the Reactive Property in Vue

Now, let’s define the rectHeight property in your vue.js file.
  1. Open vue.js and update your data() section:
    • Add a comma after any previous properties
    • Below your existing properties, type rectHeight: with the value "100"
    2.
  2. Save your file. The square should reappear change because Vue is now controlling it! You can change the value of rectHeight to something else like "200", and Vue will update the shape's height accordingly

Hiding or showing shapes and text reactively

In Vue.js, you can dynamically control the visibility of SVG elements using the v-show directive. Instead of manually removing elements, Vue will show or hide them based on a data property.

In this exercise, you will:
  1. Use Vue’s v-show directive to control the visibility of an SVG element
  2. Define a Vue data property that determines whether a shape is shown or hidden

Step 1: Add Vue's v-show Directive

  1. Open index.html and locate the <rect> element. Add the v-show directive along with a meaningful property name such as "isRectangleVisible"
  2. Save your changes. You will notice the square disappears in the live preview — this is expected because Vue doesn’t know what isRectangleVisible is yet. We will define it in the next step.

Step 2: Define the Visibility Property in Vue

  1. In vue.js, define isRectangleVisible in the data() section:
    • Add a comma after any previous properties
    • Below your existing properties, type isRectangleVisible: with the value true
    • Note the value true has no quotation marks
    2.
  2. Save your files and check the live preview where the rectangle should reappear
  3. Try changing isRectangleVisible to false in vue.js and see how the rectangle disappears again
    • If isRectangleVisible is true, the rectangle remains visible
    • If isRectangleVisible is false, the rectangle is hidden

    4. If the live preview does not update immediately, try refreshing the window by clicking the ⟳ icon in the live preview.

Now, apply the same concept to show or hide other SVG elements interactively!
  1. Choose one shape and one text element
  2. Add v-show in the SVG element along with a meaningful property name (e.g., isCircleVisible or isTriangleLabelVisible)
  3. Open vue.js and type the property name under data() and give it a value of true or false
    • ⚠ Reminder: Don't forget to add a comma after any previous properties
  4. Test your changes! For example, manually change true to false in vue.js and observe the effect

Glossary

Refer to the definitions below to reinforce your knowledge.
  • SVG <text> Element → Used to add text inside an SVG graphic
  • Attributes (fill, width, height, stroke, etc.) → Modifiable properties that define how an SVG shape looks
  • Reactivity → Vue’s ability to automatically update the SVG when data changes
  • Text Interpolation ({{ }}) → Text interpolation is a way to dynamically insert text into the SVG code using double curly braces {{ }}
  • Data Properties → Variables stored in Vue’s data() function that control the user interface
  • Directives → Special Vue attributes like v-bind and v-show that control behavior
  • v-bind Directive → Dynamically binds/connects an SVG attribute (e.g., fill, width, stroke) to Vue data
  • Binding vs. Hardcoding → The difference between using Vue (v-bind:fill="rectFill") vs. static HTML (fill="blue")
