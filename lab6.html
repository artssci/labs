Lab 6: Creating a Data Dashboard

General Description

In this lab, you will build a Data Dashboard to visualize a topic of your choice. You will learn to use specialized Vuetify components to transform complex datasets into an interactive user experience.

While you are free to select your own theme (e.g., Sports Stats, Financial Trends, or Environmental Data), this lab will use the 2025-2027 Canada Immigration Levels Plan as the primary example to demonstrate how to map data to various UI components.

Learning Objectives

  1. Implement Time-Series Visualization logic by mapping numeric arrays to the v-sparkline component.
  2. Apply Process Decomposition by breaking down complex information into a sequential, state-driven workflow using v-stepper.
  3. Practice Data Structuring and Display by organizing raw JSON/Objects into searchable and sortable interfaces using v-data-table.
  4. Refine Component-Based Architecture skills by nesting logic-heavy components within a clean, grid-based dashboard layout.

Choose a Theme

A Data Dashboard is an information management tool that visually tracks, analyzes, and displays metrics, and key data points. Dashboards use visual elements like charts, tables, and progress trackers to help users understand complex information at a glance. Read more.

In this lab, you will build a dashboard that visualizes a specific topic using data-driven components. While this lab uses the 2025-2027 Canada Immigration Levels Plan as the primary example, you are encouraged to choose a different theme that interests you, as long as it follows the same data logic.

  1. Brainstorm a theme for your dashboard. Think of topics that involve numbers over time or multi-step processes (e.g., Sports Season Stats, Global Climate Trends, Personal Finance).
  2. Identify the following data components for your chosen theme:
    • Trend Data: At least 2 categories that have numeric values over a 3-year or 3-month period (to be used in a sparkline).
    • Process Steps: A 3-4 step explanation of a policy, workflow, or guide related to your theme (to be used in a stepper).
    • Detail Records: A list of at least 5-6 items with associated statistics (to be used in a data table).

Visualizing Trends with Sparklines

A Sparkline is a condensed, lightweight chart designed to show a trend over time at a glance. In a dashboard, these are perfect for visualizing how a specific metric (like population, sales, or scores) changes across different periods. While we use 2025-2027 immigration data as our example, you should apply this logic to the timeline relevant to your chosen theme.

Create the Trend Data

  1. In your app.js, create an Array of Objects with a title, a subtitle, and a trend array. See example below: 

const targets = [
    {
    title: 'Temporary Resident Targets',
    subtitle: 'Plan for 2025 - 2027',
    trend: [673650, 516600, 543600]
    },
    {
    title: 'Permanent Resident Targets',
    subtitle: 'Plan for 2025 - 2027',
    trend: [395000, 380000, 365000]
    }
    ];
💡 Understanding the Trend Array: The trend property is an Array of Numbers. Vuetify uses these numbers to plot points on a graph. In the example above:
  • The first number in the array represents the starting point (e.g., Year 1 (2025)).
  • The last number represents the end point (e.g., Year 3 (2027)).
  • The sparkline automatically scales based on the highest and lowest values in your array.

Render the Sparkline Cards

  1. In index.html, use a v-for loop to generate a v-card for each object in your array. (Refer to Lab 3, Section 3).
  2. Inside the card, add the <v-sparkline> component.
  3. Connect your data using the :model-value property.
  4. See example below:

<v-sparkline :model-value="target.trend"></v-sparkline>
What is :model-value? In Vuetify, :model-value tells the sparkline what data it should be visualizing. In this case, :model-value="target.trend" tells the sparkline: "Look at the trend array inside the current object and use those numbers to draw the line."
  1. Add the command auto-draw. This tells the component to animate the line drawing from left to right when the page loads.

<v-sparkline :model-value="target.trend" auto-draw ></v-sparkline>

Using Steppers For Multi-step Content

A Stepper is a specialized component used to display content through a numbered sequence. This is an ideal logic for breaking down complex workflows, multi-step instructions, or long policy documents into digestible "chunks" that a user can navigate one at a time. While we use the Canada Immigration Plan categories as our example, you can use this for any sequential information related to your theme.

Create the Content Array

  1. In your app.js, create an Array of Objects. In this example, the array is called policies.
  2. Each object should contain at least, a title (used for the step label) and a description (the main content for that step). See example below: 

const policies = [
        {
        title: 'Economy and Labour Market Needs',
        description: 'In recent years, Canada welcomed newcomers to support our economy...',
        },
        {
        title: 'Temporary Residents',
        description: 'To ensure a well-managed migration system the Government is reducing...',
        },
        {
        title: 'International Students',
        description: 'In keeping with these reductions, targets for new temporary resident...',
        },
        {
        title: 'Permanent Residents',
        description: 'The 2025-27 Levels Plan projects a decrease in overall permanent...',
        }
];

Implementing the Stepper

  1. Use the <v-stepper> component and use the :items command to generate the step headers.

<v-stepper :items="policies">
<!-- Content goes here -->
</v-stepper>
💡 What is :items? The :items command is used by the Stepper to automatically create the navigation header (the numbered circles and labels). In the example above, by passing it policies, the Stepper reads the "title" of each object to label the steps.
  1. Inside the stepper, add a <template> tag and use v-for to loop through your array.

<v-stepper :items="policies">
<template v-for="(policy, index) in policies" :key="index">
<!-- Content goes here -->
</template>
</v-stepper>
💡 What is <template>? In Vue, the <template> tag is an invisible wrapper. It also allows you to use directives like v-for or v-if.
  1. Add a dynamic v-slot to the template to ensure the content connects to the correct step number.

<v-stepper :items="policies">
<template v-for="(policy, index) in policies" :key="index" v-slot:[item.${index+1}]>
<!-- Content goes here -->
</template>
</v-stepper>
💡 What is v-slot:[item.${index+1}]? Vuetify Steppers use "slots" to decide where content appears. Because we are using a loop, we use backticks (template literals) to create a dynamic name: item.1, item.2, etc. This tells Vue: "Put this specific object's data into the corresponding numbered step."
  1. Finally, place a v-card inside the template to display the information from your objects using dot notation.

<v-stepper :items="policies">
<template v-for="(policy, index) in policies" :key="index" v-slot:[item.${index+1}]>
<v-card>
<v-card-title>{{ policy.title }}</v-card-title>
<v-card-text>{{ policy.description }}</v-card-text>
</v-card>
</template>
</v-stepper>

Data Tables & Statistics

The final layer of a dashboard is the raw data. A Data Table is a powerful component that automatically organizes an array of objects into rows and columns. This allows users to scan through large lists of information, compare specific values, and see the exact figures behind the trends shown in your sparklines.

Organizing Your Dataset

  1. In your app.js, create an array that contains your detailed records. For our immigration example, we will call this immigrationCountries.
  2. Each object in your array should represent one row in the table. Ensure every object uses the same fields (e.g., country and Number), as these keys will become the column headers.

// Example: Top Source Countries for Canadian Immigration
const immigrationCountries = [
        { country: 'India', Number: '147,190' },
        { country: 'Philippines', Number: '188,805' },
        { country: 'China', Number: '129,020' },
        { country: 'Syria', Number: '29,945' },
        { country: 'Nigeria', Number: '17,285' },
        { country: 'United States of America', Number: '33,060' }
];

Displaying the Table

  1. In your index.html, add the <v-data-table> component.
  2. Use the :items prop to connect the table to your array.

<v-data-table :items="immigrationCountries"></v-data-table>

Optional Challenge: Polishing the Dashboard

Now that your data is functional, try these challenges to enhance the visual and interactive aspects of your dashboard.

Challenge 1: Branding and Layout Styling

  1. Add a v-app-bar at the top of your page. Use the v-app-bar-title to clearly state the name of your dashboard.
  2. Differentiate the sections of your dashboard (e.g., the sparkline area vs. the table area) by applying different colors. Follow colors documentation here: https://v3.vuetifyjs.com/en/styles/colors/#classes

Challenge 2: Visualizing the Content

  1. Standard text can be overwhelming. Try adding visual cues (e.g., icons or images) to your v-stepper cards to make the information more digestible.

Challenge 3: Managing Screen Space (Collapsible Sections)

  1. Use v-expansion-panels. to make sections "collapsible" so the user can focus on one piece of data at a time. Follow Expansion Panels Documentation: https://vuetifyjs.com/en/components/expansion-panels/#api.
