Data Types and Variables

Data Types in Python are the type of values a program can use. Similarly to Vue.js, values can be text enclosed in quotes (e.g., "hello"), numbers (e.g., 3.14), and booleans (e.g., True/False).

Variables are used to store values that can be referenced and manipulated in a program. Just like in Vue.js, where we define properties in the data() function, Python variables store values that our program can use and modify.

For example, in Vue, we may define: 


const app = Vue.createApp({
  data() {
    return {
      name: 'Alice',
      age: 20
    };
  }
};

In Python, the equivalent would be:


name = "Alice"
age = 20

To practice variables and data types in Python, let's create a program that stores someones age and hometown in variables and prints them:

  1. create a new file called variables.py and save it inside your Python folder
  2. Type the following code inside the file:
    3. 
name = "Alice"
age = 20
hometown = "Toronto"
print("My name is", name + ".", "I am", age, "years old and from", hometown)
  3. Save the file
  4. In Windows, run the script by typing:
    5. python variables.py
  5. In macOSC, run the scrit by typing:
    6. 
python3 variables.py
  6. After running the program you should see "My name is Alice. I am 20 years old and from Toronto" printed in the terminal. This means the program ran successfully

Modify the variables name, age and hometown from the exercise above to print your name, age, and hometown.

Interactivity: Getting User Input

Python allows for interactivity through user input, similar to how Vue.js enables dynamic updates through v-on:click and v-model. However, in Vue, user input updates data properties in real time, whereas in Python, we capture input with the input() function and store it in a variable for later use.

To practice getting user input, let's write a program that asks for the user's name and greets them:

  1. Create a new file called user-input.py and save it inside your Python folder
  2. Type the following code inside the file:

name = input("What is your name? ")

Basic Math Operations

Python supports fundamental math operations, similar to JavaScript:

  • Addition (+)
  • Subtraction (-)
  • Multiplication (*)
  • Division (/)

To practice math operations, let's create a simple calculator that adds two numbers:

  1. create a new file called add-numbers.py and save it inside your Python folder
  2. Type the following code inside the file:
    3.

  5. In macOSC, run the script by typing:

Modify the sum = num1 + num2 and print("The sum is:", sum) from the code above to multiply two numbers and print the result

If-Else Conditions

Conditional statements in Python allow us to execute different code based on certain conditions. The if statement checks if a condition is true, and the else statement executes code when the condition is false. This is similar to JavaScript's ternary operator (condition ? trueValue : falseValue), but in Python, we use explicit if-else blocks.

To practice if-else conditions, let's write a program that checks if a number is greater than 10:

  1. create a new file called condition.py and save it inside your Python folder
  2. Type the following code inside the file:
    3. 
num = int(input("Enter a number: "))
if num > 10:
    print("Your number is greater than 10")
else:
    print("Your number is not greater than 10")
  3. Save the file changes
  4. In Windows, run the script by typing:
    5. python condition.py
  5. In macOSC, run the script by typing:
    6. 
python3 condition.py
  6. After running the program you should be asked to enter a number for the program to check if the condition is met

Modify if num > 10: to check if the input number is equal to 10
