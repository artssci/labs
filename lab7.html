General Description

In this assignment, you will practice dynamically updating various elements within your custom interface, making it more engaging and functional.

This assignments introduces new topics, including: Using <image> elements to display pictures dynamically; <input> and <textarea> elements to allow user input; <p> (paragraph) elements to display larger dynamic content; and utilizing v-model to bind user input from text fields and text areas.

Learning Objectives

  • Build upon the skills you’ve developed in previous labs to add interactivity to your custom intrface
  • Apply your understanding of data, methods, and events in Vue.js to create interactive interface components

Glossary

Refer to the definitions below to reinforce your knowledge.
  • SVG <text> Element → Used to add text inside an SVG graphic
  • Attributes (fill, width, height, stroke, etc.) → Modifiable properties that define how an SVG shape looks
  • Reactivity → Vue’s ability to automatically update the SVG when data changes
  • Text Interpolation ({{ }}) → Text interpolation is a way to dynamically insert text into the SVG code using double curly braces {{ }}
  • Data Properties → Variables stored in Vue’s data() function that control the user interface
  • Directives → Special Vue attributes like v-bind and v-show that control behavior
  • v-bind Directive → Dynamically binds/connects an SVG attribute (e.g., fill, width, stroke) to Vue data
  • Binding vs. Hardcoding → The difference between using Vue (v-bind:fill="rectFill") vs. static HTML (fill="blue")
  • Method → In Vue.js, a method is a function defined in the methods section. It is used to perform actions or operations in response to events, such as user interactions or other triggers. Methods can access and modify component data, and they are typically invoked with event listeners like v-on to make the app interactive.
  • Function → A function is a set of instructions that performs a specific task. You can think of it like a recipe: you give it ingredients (inputs), it follows the steps, and then it gives you a result (output).
  • Lists (Arrays) → In JavaScript, a 'List' is a synonym for an 'Array'. For beginners, think of an array as a list, like a shopping list. This list has slots where you put the items you want to buy. In JavaScript, these slots are called 'indices' and the items in the list are called 'elements'
  • Objects → An object in JavaScript is a data structure used to store related data collections. It stores data as key-value pairs, where each key is a unique identifier for the associated value. Objects are dynamic, which means the properties can be added, modified, or deleted at runtime
  • Ternary Operator → A ternary operator is an operator that takes three inputs and returns one output. It's also known as the conditional operator. One can read it aloud as "if a then b otherwise c"

New Entries: <image> , <input>, <textarea>, <p>, and v-model

  • <input> → An HTML element that users to input data. It supports various types, such as text, numbers, and more
  • <textarea> → An HTML element enabling users to enter sizable amounts of free-form text
  • <p> → An HTML element that defines a paragraph of text
  • <image> → An SVG element that allows images (such as SVG, JPEG, PNG, or GIF) to be embedded within SVG content. It requires attributes like href (specifying the image source), width, and height to define the image's dimensions
  • v-model → A Vue.js directive that creates a two-way data binding on form input elements, syncing the input value with a component's data property
