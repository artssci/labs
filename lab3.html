Practice wireframing a calendar interface in Figma

A wireframe is a simple visual guide that represents the skeletal framework of a software interface. Think of it as the blueprint for your final design. Wireframes need to be basic enough so that other designers and developers can understand the ideas.

A grayscale or low fidelity wireframe is the most basic type of wireframing. It’s so simplistic, that paper and pen will still suffice as a way to represent your ideas. Low fidelity wireframes are done in grayscale with a focus on layout, that is, the arrangement of items within the screen.   1. Create a New File: One of the team members should start by creating a new file by selecting Create New > Design File
  2. Name the File: Another team member should name the file. Use the navigation panel (left panel) to name the file "calendar wireframe"
  3. Create a Frame: A third team member should use the Frame Tool in the toolbar to draw a frame with dimensions 1440 x 1024
  4. Design the Calendar: All team members should use the Shape and Text tools to design the calendar. The example below uses the font Gochi Hand, but feel free to choose any font available in Figma
  5. Export the Wireframe: Export your wireframe as an SVG with the option outline text enabled. This ensures your font choices are preserved. If you're unsure where to find this option, ask your professor for guidance

Brainstorm ideas for your own software interface

Work with your team members to brainstorm ideas for a software interface. During your discussion, consider the following questions:
  1. What primary problem is the software solving?
    • Identify the main issue or need that the software addresses
  2. What would you like the software to do?
    • Define the key functionalities or goals the software should achieve
  3. What actions should users be able to perform?
    • List the tasks or operations the users should accomplish with the software
  4. What visual elements do you need visible in the interface to allow those actions
    • Determine the layout and components (e.g., buttons, menus, icons) required for an intuitive and effective user experience

Develop your own software interface in Figma

Work with your team to design a simple interface based on your brainstorming discussion. Follow these steps:
  1. Create a New File: One team member should create a new file by selecting Create New > Design File
  2. Name the File: Another team member should name the file. Choose any name you like for the file
  3. Create a Frame: A third team member should create a frame using the Frame Tool with dimensions 1440 x 1024.
  4. Design the Interface: All team members should collaborate to combine shapes and text to create the skeleton of a software interface you have agreed upon
  5. Export the Wireframe: Export your wireframe as an SVG with the option outline text enabled. This ensures your font choices are preserved. If you're unsure where to find this option, ask your professor for guidance
